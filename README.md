# Premium QR Generator

A modern Python project to generate stylish QR codes with custom colors, logo support and dark mode UI.

---

# Overview

A modern desktop-based QR Code Generator built using Python and CustomTkinter. This project allows users to create stylish QR codes with custom colors, logo embedding, live preview and dark mode interface.

---

# 🛠️ Built With

* Language: Python
* GUI Library: CustomTkinter
* Libraries: qrcode, Pillow
* Concepts: GUI Development, Image Processing, File Handling

---

# Status

✅ Completed Basic Version

---

# ✨ Features

* 🎨 Custom QR colors
* 🌙 Dark mode modern UI
* 🖼️ Live QR preview inside app
* 🏷️ Add logo in center of QR
* 💾 Save generated QR automatically
* 🔗 Generate QR from text or URL
* ⚡ Fast and lightweight desktop app

# 🚀 How to Run

## Step 1: Clone the Repository

```bash
git clone https://github.com/prathmesh-nakate/Premium-QR-Generator.git

cd Premium-QR-Generator
```

---

## Step 2: Install Requirements

```bash
pip install -r requirements.txt
```

---

## Step 3: Run the Application

```bash
python qr_generator.py
```
